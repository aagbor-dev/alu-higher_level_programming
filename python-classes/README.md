# Python - Classes and Objects

Python scripts that practice defining classes and working with objects.

- `0-square.py`: empty class Square that defines a square
- `1-square.py`: Square class with a private size
- `2-square.py`: Square class with size validation
- `3-square.py`: Square class with an area method
- `4-square.py`: Square class with a size getter and setter
- `5-square.py`: Square class that prints itself with #
- `6-square.py`: Square class with a position
