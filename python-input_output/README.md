# Python - Input/Output

Python scripts that practice reading and writing files.

- `0-read_file.py`: function that reads a text file and prints it to stdout
- `1-write_file.py`: function that writes a string to a text file
- `2-append_write.py`: function that appends a string to a text file
- `3-to_json_string.py`: function that returns the JSON representation of an object
- `4-from_json_string.py`: function that returns an object from a JSON string
- `5-save_to_json_file.py`: function that writes an object to a text file as JSON
- `6-load_from_json_file.py`: function that creates an object from a JSON file
