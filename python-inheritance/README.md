# Python - Inheritance

Python scripts that practice inheritance, subclasses and introspection.

- `0-lookup.py`: function that returns the list of available attributes and methods of an object
- `1-my_list.py`: class MyList that inherits from list and prints itself sorted
- `tests/1-my_list.txt`: doctests for MyList
- `2-is_same_class.py`: function that checks for the exact class of an object
- `3-is_kind_of_class.py`: function that checks the class or a parent class
- `4-inherits_from.py`: function that checks for an instance of a subclass
- `5-base_geometry.py`: empty class BaseGeometry
- `6-base_geometry.py`: BaseGeometry with an area method that raises an exception
