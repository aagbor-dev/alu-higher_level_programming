Tests for the MyList class in 1-my_list.py
==========================================

Import the class:

    >>> MyList = __import__('1-my_list').MyList

An empty list prints as an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

It is still a list:

    >>> isinstance(my_list, list)
    True

Elements are printed in ascending order:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list is not changed:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

A list that is already sorted:

    >>> my_list = MyList([1, 2, 3])
    >>> my_list.print_sorted()
    [1, 2, 3]

A single element:

    >>> my_list = MyList([7])
    >>> my_list.print_sorted()
    [7]

Negative numbers and zero:

    >>> my_list = MyList([3, -1, 0, -5])
    >>> my_list.print_sorted()
    [-5, -1, 0, 3]

Duplicates are kept:

    >>> my_list = MyList([2, 1, 2, 1])
    >>> my_list.print_sorted()
    [1, 1, 2, 2]
