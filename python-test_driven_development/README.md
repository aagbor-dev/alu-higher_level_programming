# Python - Test-driven development

Python functions and the doctests that describe their behavior.

- `0-add_integer.py`: function that adds 2 integers
- `tests/0-add_integer.txt`: doctests for add_integer
- `2-matrix_divided.py`: function that divides all elements of a matrix
- `tests/2-matrix_divided.txt`: doctests for matrix_divided
- `3-say_my_name.py`: function that prints a first and a last name
- `tests/3-say_my_name.txt`: doctests for say_my_name
- `4-print_square.py`: function that prints a square with the character #
- `tests/4-print_square.txt`: doctests for print_square
- `5-text_indentation.py`: function that prints a text with a gap after . ? and :
- `tests/5-text_indentation.txt`: doctests for text_indentation
- `tests/6-max_integer_test.py`: unittests for max_integer
