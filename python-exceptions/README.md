# Python - Exceptions

Python scripts that practice handling exceptions with try/except.

- `0-safe_print_list.py`: function that prints x elements of a list safely
- `1-safe_print_integer.py`: function that prints an integer safely
- `2-safe_print_list_integers.py`: function that prints the first x integers of a list
- `3-safe_print_division.py`: function that divides two integers and prints the result in `finally`
- `4-list_division.py`: function that divides two lists element by element
- `5-raise_exception.py`: function that raises a TypeError
- `6-raise_exception_msg.py`: function that raises a NameError with a message
