# SQL - Introduction

SQL scripts that practice basic queries on a MySQL server.

- `0-list_databases.sql`: script that lists all databases of the MySQL server
- `1-create_database_if_missing.sql`: script that creates the database hbtn_0c_0
- `2-remove_database.sql`: script that deletes the database hbtn_0c_0
- `3-list_tables.sql`: script that lists the tables of a database
- `4-first_table.sql`: script that creates the table first_table
- `5-full_table.sql`: script that prints the full definition of first_table
- `6-list_values.sql`: script that lists all rows of first_table
- `7-insert_value.sql`: script that inserts a row in first_table
- `8-count_89.sql`: script that counts the records with id = 89 in first_table
- `9-full_creation.sql`: script that creates second_table and adds several rows
- `10-top_score.sql`: script that lists the records of second_table by best score
- `11-best_score.sql`: script that lists the records with a score of 10 or more
- `12-no_cheating.sql`: script that updates the score of Bob to 10
- `13-change_class.sql`: script that removes the records with a score of 5 or less
- `14-average.sql`: script that computes the average score
- `15-groups.sql`: script that counts the records for each score
- `16-no_link.sql`: script that lists the records that have a name
