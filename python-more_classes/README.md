# Python - More Classes and Objects

Python scripts that practice classes, properties and special methods.

- `0-rectangle.py`: empty class Rectangle that defines a rectangle
- `1-rectangle.py`: Rectangle class with validated width and height
- `2-rectangle.py`: Rectangle class with area and perimeter
- `3-rectangle.py`: Rectangle class that prints itself with #
- `4-rectangle.py`: Rectangle class with a repr that works with eval
- `5-rectangle.py`: Rectangle class that prints a message when deleted
- `6-rectangle.py`: Rectangle class that counts its instances
