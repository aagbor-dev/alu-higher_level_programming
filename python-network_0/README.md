# Python - Network #0

Bash scripts that practice HTTP requests with curl.

- `0-body_size.sh`: script that displays the size in bytes of the body of a response
- `1-body.sh`: script that sends a GET request and displays the body of a 200 response
- `2-delete.sh`: script that sends a DELETE request and displays the body
- `3-methods.sh`: script that displays all the HTTP methods a server accepts
- `4-header.sh`: script that sends a GET request with a custom header
- `5-post_params.sh`: script that sends a POST request with two variables
