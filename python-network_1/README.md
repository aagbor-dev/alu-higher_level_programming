# Python - Network #1

Python scripts that practice HTTP requests with urllib and requests.

- `0-hbtn_status.py`: script that fetches https://alu-intranet.hbtn.io/status and displays the body
- `1-hbtn_header.py`: script that displays the X-Request-Id header of a response
- `2-post_email.py`: script that sends a POST request with an email and displays the body
- `3-error_code.py`: script that displays the body of a response or the error code
- `4-hbtn_status.py`: script that fetches the status page with the requests package
- `5-hbtn_header.py`: script that displays the X-Request-Id header with requests
- `6-post_email.py`: script that sends a POST request with an email, using requests
- `7-error_code.py`: script that displays the body or the error code, using requests
- `8-json_api.py`: script that sends a letter to a search API and displays the result
- `10-my_github.py`: script that displays the GitHub id of a user
